# Penguins Species Classification

## Overview

This project explores machine learning classification techniques using the Palmer Penguins dataset. The main objective is to classify penguins into their respective species using different classification algorithms.

The project compares three machine learning models:

- Decision Trees
- Random Forest
- Support Vector Machines (SVM)

## Objectives

- Explore and prepare the dataset for classification.
- Apply different supervised machine learning algorithms.
- Compare the performance of the selected models.
- Evaluate the models using classification metrics and visualizations.

## Methods

The analysis focuses on three classification approaches:

1. **Decision Tree:** A tree-based model used to identify patterns and decision rules in the data.
2. **Random Forest:** An ensemble learning method that combines multiple decision trees.
3. **Support Vector Machine (SVM):** A classification algorithm that identifies decision boundaries between species.

## Dataset

The Palmer Penguins dataset contains information about penguins, including physical measurements and species labels.
